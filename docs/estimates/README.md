1. Photos: react, comment, save and delete, with "Photo removed" in chat (journey 14), and the photo store of a deployed system, which the album's zip and chat photos need too.
2. Join with a code, which the welcome screen now links to (journey 15).

4. The SMS and email providers, which the crew invites need too.
5. Reliability: a saved answer for every screen and an app that opens without a connection.
