# L2 - Detailed Requirements

Each L2 traces to one L1 in `L1.md` and uses its roles and terms. Every acceptance test names the
L2 it covers in a header comment (`// Traces to: L2-021`).

The designs these requirements come from use one cast: Mara Okafor is the Host of Lakeside
Weekend (🏕️, Teal, 14 members, wraps up Sunday at 6 pm); Joel Kim is the person joining it. The
criteria reuse them.

## L2-001: Landing page content
**Traces to:** L1-001

The landing page explains Popkin to a visitor in six sections, in this order: the hero, how it
works, ideas, the comparison with a group chat, the statement that it is free, and the footer.

**Acceptance Criteria:**
1. Given a visitor, when the landing page opens, then the hero shows the headline "Your people, popped up in seconds.", one paragraph, a "Start a Popkin" button, the line "Free. Takes about a minute." and a preview of a Popkin.
2. Given the landing page, when the visitor reaches "Scan. Join. You're in.", then three numbered steps appear in order: "Pop one up", "Share the QR code", "You're together".
3. Given the landing page, when the visitor reaches the ideas section, then four examples appear (Small group, Hackathon, Team, Family trip), each with its emoji, colour, a sentence and its length.
4. Given the landing page, when the visitor reaches "Better than a group chat.", then a comparison shows five rows (Joining, Photos, Plans, Video, The end), each with a group chat column and a Popkin column, and each column is told apart by an icon and its heading, not by colour alone.
5. Given a viewport narrower than 768 px, when the landing page opens, then the hero, the steps and the ideas each stack in one column and the page does not scroll sideways.
6. Given a viewport at least 1024 px wide, when the landing page opens, then the hero shows the text beside the preview and the ideas show four across.

## L2-002: Landing page actions
**Traces to:** L1-001

The landing page offers one primary action, starting a Popkin, and a way in for people who have
an account.

**Acceptance Criteria:**
1. Given a visitor, when they choose "Start a Popkin" in the navigation, the hero or the closing section, then the sign-up screen opens.
2. Given a visitor, when they choose "Sign in", then the sign-in screen opens.
3. Given a signed-in person, when they open the landing page address, then My Popkins opens instead.
4. Given a viewport narrower than 640 px, when the landing page opens, then the navigation shows the logo and "Start a Popkin" and the "Sign in" link is in the footer.
5. Given the navigation, when the visitor chooses "How it works" or "Ideas", then the page scrolls to that section and moves focus to its heading.

---

## L2-003: Sign up with a name and a phone number or an email
**Traces to:** L1-002

Signing up asks for a name and one way to reach the person. It never asks for a password.

**Acceptance Criteria:**
1. Given a visitor on the sign-up screen, when it opens, then it asks "First, what should we call you?", shows a "Your name" field and a "Phone number" field, and offers a switch between "Phone" and "Email".
2. Given the sign-up screen, when the visitor switches to "Email", then the second field becomes "Email", keeps the keyboard suited to an email address, and the name is kept.
3. Given a name and a valid phone number or email, when the visitor chooses "Continue", then the button reads "Sending your code…", is disabled until the request ends, and the code screen opens when it succeeds.
4. Given a phone number with too few digits, when the visitor chooses "Continue", then no code is sent, the field is marked invalid and the message "That number looks a digit short." appears under it and is announced.
5. Given an email without a valid address, when the visitor chooses "Continue", then no code is sent, the field is marked invalid and the message "That email doesn't look quite right." appears under it and is announced.
6. Given an empty name, when the visitor chooses "Continue", then no code is sent and the name field is marked invalid with a message that says to enter a name.
7. Given the sign-up screen, when it opens, then it states that continuing accepts the Terms and the Privacy notice, and both are links.
8. Given the request to send a code fails, when the failure returns, then what the visitor typed is kept, a message says the code could not be sent and "Continue" is enabled again.

---

## L2-004: Confirm the six-digit code
**Traces to:** L1-002

A six-digit code sent to the phone number or email proves the person owns it.

**Acceptance Criteria:**
1. Given a code has been sent, when the code screen opens, then it names the phone number or email the code went to, with all but the last two characters of a phone number masked.
2. Given the code screen, when the person enters the six correct digits, then they are signed in and the next step of their journey opens without a further tap.
3. Given the code screen, when the person enters six digits that do not match, then the field is cleared and marked invalid, the message "That code doesn't match. Try again." is announced and the count of attempts goes up by one.
4. Given a code that was sent more than 10 minutes ago, when the person enters it, then it is refused with the message "That code has expired." and a "Send a new code" action.
5. Given the person pastes a six-digit code or their device offers it from a message, when it is filled in, then it is submitted as if typed.
6. Given the code field, when anything other than a digit is typed, then it is ignored.

---

## L2-005: Resend and limit codes
**Traces to:** L1-002

Codes are short lived and cannot be guessed or requested without limit.

**Acceptance Criteria:**
1. Given a code was sent less than 30 seconds ago, when the person looks at "Send a new code", then it is disabled and shows the seconds left.
2. Given 30 seconds have passed, when the person chooses "Send a new code", then a new code is sent, the earlier code stops working and a message confirms it was sent.
3. Given five wrong codes for one phone number or email, when a sixth is entered, then it is refused even if correct, and the person must request a new code.
4. Given more than five codes requested for one phone number or email within an hour, when another is requested, then it is refused with a message that says when to try again.
5. Given a code, when it is used once, then it cannot be used again.

---

## L2-006: Sign in
**Traces to:** L1-002

A person with an account signs in with the same phone number or email and a new code.

**Acceptance Criteria:**
1. Given a visitor on the sign-in screen, when they enter the phone number or email of an account and choose "Send my code", then a code is sent and the code screen opens.
2. Given a phone number or email with no account, when the visitor chooses "Send my code", then the response and the screen are the same as for an account, so that nobody learns who has one; after the code is confirmed, the person is asked for a name and an account is made.
3. Given the sign-in screen, when it opens, then it offers a way to the sign-up screen for people starting their first Popkin.
4. Given an invalid phone number or email, when the visitor chooses "Send my code", then the messages of L2-003 apply.

---

## L2-007: Sessions
**Traces to:** L1-002

A signed-in person stays signed in on their device until they sign out or the session ends.

**Acceptance Criteria:**
1. Given a signed-in person, when they close the browser and open Popkin again within 30 days, then they are still signed in.
2. Given a session that has ended, when the person opens any screen that needs one, then the sign-in screen opens and, after signing in, the screen they asked for opens.
3. Given a visitor, when they open any screen other than the landing page, the welcome screen, sign up, sign in, the code screen or an invite, then the sign-in screen opens.
4. Given a session, when it is stored in the browser, then it is in a cookie that scripts cannot read, is sent only over HTTPS and is not sent with requests from other sites.

---

## L2-008: Name a Popkin and pick its emoji and colour
**Traces to:** L1-003

The first step of starting a Popkin gives it a name, an emoji and a colour, with a preview that
changes as they are chosen.

**Acceptance Criteria:**
1. Given a signed-in person, when "Name your Popkin" opens, then it shows a name field, twelve emoji, seven colours (Coral, Teal, Sky, Berry, Leaf, Plum, Amber), a preview and a "Looks good" button.
2. Given the screen, when the person picks an emoji or a colour, then the preview and the "Looks good" button take it at once, and the chosen emoji and colour are marked as pressed for assistive technology and shown with a ring or a dot as well as colour.
3. Given a name that is empty or only spaces, when the person looks at "Looks good", then it is disabled.
4. Given a name, when the person types past 40 characters, then no more characters are accepted and a count shows 40 of 40.
5. Given a name, an emoji and a colour, when the person chooses "Looks good", then the "How long should it last?" step opens and going back keeps all three.
6. Given the screen, when it opens for the first time, then the name is empty with the example "Thursday Night Crew" and the first emoji and the Coral colour are chosen.

## L2-009: Choose how long a Popkin lasts
**Traces to:** L1-003

The second step sets when the Popkin wraps up.

**Acceptance Criteria:**
1. Given the step "How long should it last?", when it opens, then it offers four options as one radio group: "Just today" (wraps up at midnight), "The weekend" (wraps up Sunday, 6 pm), "Until a date" and "Keep it going" (no end date), with "The weekend" chosen.
2. Given the options, when the person chooses "Until a date", then a control shows the chosen end date and time and opens a date and time picker.
3. Given the date and time picker, when the person picks a time less than one hour ahead or more than one year ahead, then it is refused with a message that states the limits.
4. Given an option is chosen, when the person chooses "Pop it up", then the button is disabled and reads "Popping it up…" until the Popkin exists, and then the created screen opens.
5. Given creating the Popkin fails, when the failure returns, then the choices are kept, a message says the Popkin could not be created and "Pop it up" is enabled again.
6. Given the step, when it opens, then it says the length can be changed later and that everyone gets a recap when it ends.
7. Given the radio group, when the person uses the arrow keys, then the choice moves between the four options.

## L2-010: The Popkin is created
**Traces to:** L1-003

When a Popkin exists, its Host is given its invite straight away.

**Acceptance Criteria:**
1. Given a Popkin has just been created, when the created screen opens, then it reads "Pop! {name} is up.", shows the Popkin's emoji in its colour, a QR code for its invite link and the link as text.
2. Given the created screen, when the Host chooses "Copy link", then the invite link is on the clipboard, the action reads "Copied" for 3 seconds and the change is announced.
3. Given the created screen, when the Host chooses "Text it", then the device's messaging app opens with the invite link in the message.
4. Given the created screen on a device with a share sheet, when the Host chooses "Share", then the share sheet opens with the invite link; on a device without one, "Share" is not shown.
5. Given the created screen, when the Host chooses "Go to {name}", then the Popkin home opens.
6. Given the person who created the Popkin, when it exists, then they are its Host and its first member.
7. Given the person prefers reduced motion, when the created screen opens, then the confetti burst does not play.

## L2-011: Invite with a QR code or a link
**Traces to:** L1-004

Any member invites people from the Popkin home.

**Acceptance Criteria:**
1. Given a member on the Popkin home of an active Popkin, when they choose "Invite", then a dialog titled "Bring someone in" opens with the Popkin's QR code, its emoji and name, its invite link and a "Copy invite link" action.
2. Given the invite dialog, when the member chooses "Copy invite link", then the link is on the clipboard and the action reads "Copied" for 3 seconds.
3. Given the invite dialog, when the member presses Escape, chooses "Close" or chooses outside it, then it closes and focus returns to "Invite".
4. Given a viewport narrower than 640 px, when the invite dialog opens, then it is a sheet fixed to the bottom of the screen; at 640 px and wider it is centred.
5. Given an invite link, when it is made, then its code is at least 8 characters from an unguessable source or a slug the Host chose, and it is unique.
6. Given the QR code, when it is scanned with a phone camera, then it opens the invite link.

## L2-012: See the invite before joining
**Traces to:** L1-004

An invite link shows what the person is joining before they commit.

**Acceptance Criteria:**
1. Given a person who is not a member, when they open an invite link to an active Popkin, then they see who invited them, the Popkin's emoji, colour and name, the number of members with up to five avatars, when it wraps up and a "Join" button, with the line "Free, no app to download."
2. Given a Popkin with no end date, when its invite opens, then no end time is shown.
3. Given a visitor on an invite, when they choose "Join", then they sign up or sign in (L2-003 to L2-006) and continue to the profile step without opening the link again.
4. Given a signed-in person who is already a member, when they open the invite link, then the Popkin home opens.
5. Given the invite screen, when it is shown to someone who is not a member, then it reveals no message, photo, experience or member name other than the first name and avatar of the person who invited them.

## L2-013: Join with a name and an optional photo
**Traces to:** L1-004

Joining asks only how the person wants to be known in this Popkin.

**Acceptance Criteria:**
1. Given a signed-in person joining a Popkin, when the profile step opens, then it asks "How should people know you?", shows their account name in "Your name" with the hint "First name is plenty." and offers to add a photo, marked as optional.
2. Given the profile step, when the person adds a photo, then it replaces their initial in the preview; a photo must be a JPEG, PNG, WebP or HEIC image of at most 10 MB, and anything else is refused with a message.
3. Given an empty name, when the person looks at "I'm in", then it is disabled.
4. Given a name, when the person chooses "I'm in", then the button is disabled and reads "Joining…" until they are a member, and then the welcome screen opens.
5. Given joining fails, when the failure returns, then the name and photo are kept, a message says so and "I'm in" is enabled again.
6. Given a person with no photo, when they appear anywhere in Popkin, then their avatar shows their initials on a colour that stays the same for them.

A new member is welcomed and the group is told.

2. Given the welcome screen, when the member chooses "Say hi to everyone", then the Everyone thread opens with focus in the message field.
3. Given the welcome screen, when the member chooses "See the photos", then Photos opens.
4. Given a person has just joined, when members look at the Everyone thread, then a note reads "{name} popped in. Say hi! 👋" at the time they joined.

A person without the link joins by scanning the QR code inside Popkin or typing its code.

**Acceptance Criteria:**

5. Given a visitor on the welcome screen, when they choose "Join with a code", then a screen asks for the invite code or link.

## L2-016: Invites that cannot be joined
**Traces to:** L1-004

An invite to a wrapped-up Popkin, or one that does not exist, says so and offers a way forward.

**Acceptance Criteria:**
1. Given an invite link to a wrapped-up Popkin, when a person who is not a member opens it, then they see its emoji muted, its name and member count, a sentence that it has wrapped up and to ask the person who invited them for the next one, and no "Join" button.
2. Given an invite link that matches no Popkin, when it is opened, then a screen says the invite cannot be found and offers "Start a Popkin" and "Join with a code".
3. Given a member of a wrapped-up Popkin, when they open its invite link, then its recap opens.

## L2-017: List my active Popkins
**Traces to:** L1-005

My Popkins lists the Popkins a member belongs to, the most recently active first.

**Acceptance Criteria:**
1. Given a member of at least one active Popkin, when My Popkins opens, then each active Popkin is a card in its colour with its emoji, name, the latest message with its sender's first name, up to three member avatars with a count of the rest, and either the time left or "Ongoing".
2. Given a Popkin with unread messages, when its card shows, then a badge shows the count, "99+" above 99, with an accessible name that says what is counted.
3. Given My Popkins, when the member chooses a card, then that Popkin's home opens.
4. Given My Popkins, when the member chooses "New Popkin", then "Name your Popkin" opens.
5. Given My Popkins, when the member chooses their avatar, then their account opens.
6. Given a person who belongs to no Popkin, when My Popkins opens, then it explains what a Popkin is and offers "Start a Popkin" and "Scan to join".
7. Given the list is loading, when My Popkins shows, then skeleton cards of the same size as the real cards are shown.

## L2-018: List my wrapped-up Popkins
**Traces to:** L1-005

Wrapped-up Popkins stay within reach under the active ones.

**Acceptance Criteria:**
1. Given a member of at least one wrapped-up Popkin, when My Popkins opens, then a "Wrapped up" section lists each with its emoji muted, its name, the date it wrapped up, the number of people and photos, and a "Recap" label.
2. Given the "Wrapped up" section, when the member chooses a Popkin, then its recap opens.
3. Given a member with no wrapped-up Popkin, when My Popkins opens, then the "Wrapped up" section is not shown.

## L2-019: Popkin home
**Traces to:** L1-006

The home of a Popkin summarises it and leads to everything in it.

**Acceptance Criteria:**
1. Given a member, when the Popkin home opens, then the header shows the Popkin's emoji, name, up to four avatars, the member count, and, for a Popkin with an end date, the time left and when it wraps up.
2. Given the Popkin home, when it opens, then it offers "Group call" and "Invite", and "Group call" is in the Popkin's colour.
3. Given the Popkin home, when there are messages in Everyone, then a "Chat" card shows the three latest with sender, time and one line each, and the number that are new to the member; choosing the card opens Chat.
4. Given the Popkin home, when there are photos, then a "Photos" section shows the count, the six latest as thumbnails and "See all"; choosing a thumbnail opens that photo.
5. Given the Popkin home, when there are experiences, then an "Experiences" section shows the count, the highest-rated experience with its score and number of ratings, and "See all".
6. Given the Popkin home, when it opens, then a "Members" section shows the count and the members, the Host first and labelled "Host".
7. Given any screen of a Popkin that shows the tabs, when it opens, then the tabs "Home", "Chat", "Photos" and "Experiences" are shown, the current one is marked with `aria-current` and a heavier label and icon, and "Chat" carries the count of unread messages.
8. Given a Popkin with no messages, photos or experiences, when its home opens, then each section says what it is for and offers its first action.
9. Given one section fails to load, when the home shows, then that section says so with "Try again" and the other sections still show.

## L2-020: Popkin settings
**Traces to:** L1-006

The Host changes how a Popkin looks and how long it lasts.

**Acceptance Criteria:**
1. Given the Host on the Popkin home, when they choose "Popkin settings", then a menu offers "Edit name and look", "Change how long it lasts", "Invite people" and "Wrap up".
2. Given a member who is not the Host, when they choose "Popkin settings", then the menu offers "Invite people" and "Leave this Popkin" only.
3. Given the Host in "Edit name and look", when they save a new name, emoji or colour, then every screen of the Popkin shows it for every member without a reload, under the rules of L2-008.
4. Given the Host in "Change how long it lasts", when they save a new length, then the time left updates for every member, under the rules of L2-009.
5. Given a member who is not the Host, when they send a request to change the Popkin's name, emoji, colour or length, then it is refused with 403.
6. Given a save fails, when the failure returns, then the dialog stays open with what was entered and a message that says so.

## L2-021: Send a message to everyone
**Traces to:** L1-007

The Everyone thread is the heart of a Popkin.

**Acceptance Criteria:**
1. Given a member in the Everyone thread, when it opens, then the header shows the Popkin's emoji and name, the member count and how many are here now, and messages appear oldest first with the latest in view.
2. Given a message from someone else, when it shows, then it carries their avatar and first name; consecutive messages from one person show the name and avatar once.
3. Given a message from the member, when it shows, then it is on the right, in the Popkin's colour, with its time.
4. Given messages from different days, when they show, then a divider names each day ("Today", "Yesterday", then the weekday or date).
5. Given a message field with text, when the member chooses "Send" or presses Enter, then the message appears in the thread at once and the field empties; Shift+Enter adds a line.
6. Given an empty message field, when the member looks at "Send", then it is disabled.
7. Given a message, when the member types past 2,000 characters, then no more are accepted and a count shows.
8. Given a Popkin with no messages, when the thread opens, then it reads "It's quiet in here. For now.", suggests three openers and choosing one puts it in the message field.

## L2-022: Conversations
**Traces to:** L1-007

The Chat tab lists the member's threads in one Popkin.

**Acceptance Criteria:**
1. Given a member, when the Chat tab opens, then "Everyone" is first and larger than the rest, in the Popkin's colour, with its latest message, time and unread count.
2. Given the member has direct messages, when the Chat tab opens, then they are listed under "Direct messages", the most recent first, each with the other member's avatar and name, the latest message (prefixed "You:" when the member sent it), its time and an unread mark.
3. Given an unread direct message, when its row shows, then the name is bold and a dot with the accessible name "Unread" shows.
4. Given the Chat tab, when the member chooses "New message", then a dialog lists the Popkin's members other than the member, with a search field, and choosing one opens the direct message with them.
5. Given the member has no direct messages, when the Chat tab opens, then the section says that direct messages are between two members and offers "New message".

## L2-023: Direct messages
**Traces to:** L1-007

Two members of one Popkin talk privately.

**Acceptance Criteria:**
1. Given a member in a direct message, when it opens, then the header shows the other member's avatar and name and "From {emoji} {Popkin name}", and the thread starts with the line "Only you two can see this".
2. Given a direct message, when either member sends a message, then only the two of them can read it; a request for it from anyone else is refused with 404.
3. Given a direct message, when it opens, then everything a member can do in Everyone (text, photos, reactions, replies) works the same way.
4. Given two people who share no active Popkin, when one tries to start a direct message with the other, then it is refused.
5. Given the Popkin a direct message belongs to is wrapped up, when either member opens it, then it is read-only.

---

## L2-024: React to a message
**Traces to:** L1-007

Members react to messages with emoji.

**Acceptance Criteria:**
1. Given a message, when the member presses and holds it, or focuses it and presses Enter, then a menu offers five quick reactions, "More reactions", "Reply" and "Copy"; on the member's own message it also offers "Delete".
2. Given the member picks a reaction, when it is saved, then a chip under the message shows the emoji and its count, and the member's own reaction is marked as pressed and outlined as well as tinted.
3. Given the member chooses a reaction chip they already added, when it is saved, then their reaction is removed and the count goes down by one; a chip that reaches zero is removed.
4. Given a message, when a member adds a second, different emoji, then both of their reactions show.
5. Given a reaction chip, when it is read by assistive technology, then it says the emoji's name, the count and whether the member has reacted.

**Traces to:** L1-007

A reply quotes the message it answers.

## L2-026: Send photos in chat
**Traces to:** L1-007

A message carries a photo with or without text.

**Acceptance Criteria:**
1. Given the composer, when the member chooses "Photo", then they pick or take one photo, see it above the message field with a "Remove photo" action, and send it with or without text.
2. Given a message with a photo, when it shows, then the photo is at most 16 rem wide at a 4:3 ratio with any text under it, and choosing it opens the photo full screen.
3. Given a photo sent in Everyone, when it is sent, then it is also added to Photos under the sender's name; a photo sent in a direct message is not.
4. Given a photo, when it is chosen, then the limits of L2-031 apply.

## L2-027: Messages arrive as they are sent
**Traces to:** L1-007

Chat is live.

**Acceptance Criteria:**
1. Given two members with the same thread open, when one sends a message, then the other sees it within 1 second on a connection with 100 ms latency, without reloading.
2. Given a member reading older messages, when a new message arrives, then the view does not move and a "New messages" control appears that scrolls to the latest.
3. Given a member is not looking at a thread, when a message arrives in it, then its unread count goes up on the Chat tab, on the Popkin home and on My Popkins.
4. Given a member opens a thread, when its latest message has been in view, then the thread's unread count is zero everywhere.
5. Given a thread with more than 50 messages, when it opens, then the latest 50 load and earlier ones load as the member scrolls up, without the view jumping.
6. Given new messages arrive while assistive technology is in use, when they arrive, then each is announced politely with its sender.

---

## L2-028: Messages that cannot be sent
**Traces to:** L1-007

A message is never lost silently.

**Acceptance Criteria:**
1. Given a message fails to send, when the failure returns, then the message stays in the thread marked "Not sent" with an icon, and offers "Try again" and "Delete".
2. Given the device is offline, when the member sends a message, then it is kept on the device, marked "Waiting to send" and sent in order when the connection returns.
3. Given the device goes offline, when a thread is open, then a banner says so and stays until the connection returns.
4. Given a member writes a message and leaves the thread without sending it, when they come back in the same session, then the text is still in the message field.

---

## L2-029: Start or join a group call
**Traces to:** L1-008

One tap puts the whole Popkin on a video call.

**Acceptance Criteria:**
1. Given a member on the Popkin home or in the Everyone thread of an active Popkin, when they choose "Group call" or "Start group call", then the browser asks for the microphone and camera and, once allowed, the call opens with the member in it.
2. Given a group call is under way, when a member looks at the Popkin home or the Everyone thread, then a banner says how many are on the call and offers "Join".
3. Given the member is the only one on the call, when the call shows, then it says it is waiting for others and offers to invite them.
4. Given the member refuses the microphone and camera, when the call cannot start, then a message explains how to allow them and offers to go back.
5. Given a call, when it opens, then the header shows the Popkin's emoji and name, how many are on the call and how long it has run.
