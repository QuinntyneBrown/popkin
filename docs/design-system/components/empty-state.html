Empty state

An icon or Popkin tile, a short heading, a sentence about what this place is for, and one action. Also used for errors and the not-found, server-error and offline pages.

WCAG 2.2 AAStatus: stableHeading, text, one action

Overview

Every list has an empty state that teaches, and every screen that loads data has an error state that keeps the chrome and offers Try again.

Anatomy

  1. Art88px icon on sand, a Popkin tile, or the mark.
  2. HeadingNunito 900 24px.
  3. TextOne or two sentences, muted.
  4. ActionOne button; a second only to go back.
