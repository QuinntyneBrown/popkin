Settings list

The deployed system's settings, read-only: each name, its key and its value, with secrets shown only as Set or Not set, under the release that is running.

Overview

Use only on Settings. It is for reading; settings change by deployment, not here.

Anatomy

  1. NameWhat the setting does.
  2. KeyThe configuration key in mono, as in docs/deployment.md.
  3. ValueThe value, or Set / Not set for a secret.
