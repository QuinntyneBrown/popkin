Component · Identity

Popkin tile

A Popkin's emoji on a squircle tinted with its colour. It identifies a Popkin wherever it appears; muted and greyed once it has wrapped up.

WCAG 2.2 AAStatus: stableDecorative

Overview

Use it beside a Popkin's name: in lists, headers, invites, chat. It is the Popkin's face.

Anatomy

  1. Squircle32% radius, 16% of the colour on the surface, a 2px inner edge.
  2. EmojiHalf the tile's size.

Responsive behaviour

  • Fixed sizes per context.

Theming

Tint and edge mix --accent into --color-bg-surface, so the tile stays soft in dark.

Accessibility

Role and pattern

aria-hidden="true": the Popkin's name is always next to it.

Keyboard

KeyAction
—Not focusable; it is read in place.

Focus

Not focusable.

Labelling

Decorative; the name carries the meaning.

Contrast

Name next to the tile

Motion

On creation and joining it springs in (the pop). Durations come from tokens, which are near zero under prefers-reduced-motion, so the press scale and colour fades disappear without extra CSS.

Touch

Part of larger targets (cards, rows).

Content

  • One emoji per Popkin.
