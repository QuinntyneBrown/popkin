Component · Identity

Avatar

A person's photo in a circle, or their initials on their own colour. Stacks overlap with a ring and end with a +count.

WCAG 2.2 AAStatus: stableDecorative beside a name

Overview

Every person appears with an avatar next to their name. Without a photo the initials sit on a colour that stays the same for that person everywhere.

Anatomy

  1. Image or initialsPhoto cropped to a circle, or up to two initials in Nunito 800.
  2. ColourThe person's own Popkin colour behind the initials.

Responsive behaviour

  • Sizes are fixed per context; avatars never scale with the viewport.

Theming

Initials sit on --accent set by data-accent on the avatar; the stack ring is --color-bg-canvas so it cuts cleanly on any page.

Accessibility

Role and pattern

A <span aria-hidden="true">: the name is always beside it. A stack carries its count in text nearby ("14 members").

Keyboard

KeyAction
—Not focusable; it is read in place.

Focus

Not focusable; when an avatar is a link (your account) the link is named ("Your account, Mara Okafor").

Labelling

Decorative next to a name; never the only way a person is identified.

Contrast

Initials on Coral
Initials on Amber

Motion

None.

Touch

An avatar that is a link is at least 36px inside a 44px target.

Content

  • Two initials at most.
