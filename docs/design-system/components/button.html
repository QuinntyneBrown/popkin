Component · Actions

Button

Buttons take an action: start a Popkin, join, send, wrap it up. They are fully rounded pills with heavy Nunito labels, and one per screen is primary.

Overview

Use a button when activating it changes something. Use a link when it only goes somewhere, and an icon button when the action is a single familiar icon in a bar.

  • Primary (coral) is the action the screen exists for: Start a Popkin, Continue, Wrap it up. One per screen.
  • Popkin takes the Popkin's own colour. Use it for the main action inside a Popkin or once its colour is chosen: Pop it up, Join, Group call.
  • Secondary (white, hairline, soft shadow) sits next to a primary: Join with a code, Invite, See the photos.
  • Ghost (sand, the base .btn) is a quiet action inside dense content: Copy link.
  • Quiet (no fill) is the escape hatch under a primary: Not yet, Cancel, Stay signed in.
  • Danger confirms something that cannot be undone: Leave, Delete my account. Only inside a confirming dialog.
  • On colour (white on coral) is the action on a coral band, such as the landing page's closing call to action.
  • Floating action (.fab) is the add action that floats over a list: New Popkin, Add, Share one.

Anatomy

  1. Leading icon (optional)20px Lucide icon, inherits the label colour, aria-hidden.
  2. LabelNunito 800, a verb phrase in sentence case; the accessible name.
  3. ContainerA full pill: --control-height-lg tall, 28px side padding, soft shadow on filled variants.

Both themes

  • Busy sets aria-busy="true" and disabled, shows a spinner and changes the label to what is happening: "Sending your code…", "Wrapping up…".
  • Disabled is for a form that is not ready yet, such as "Looks good" before the Popkin has a name. Say why next to it when it is not obvious.
  • Active scales the button to 97% for 150 ms.

Responsive behaviour

  • Under 576px the screen's main action is a block button at the foot of the column, inside the sticky footer, within reach of the thumb.
  • Pairs stack: primary on top, secondary or quiet under it, each full width.
  • From 576px the app column stays 28rem wide, so block buttons never stretch further.
  • On the landing page the hero button is inline beside its supporting line and wraps under it on phones.

Theming

Filled variants read --color-accent, --accent (the Popkin colour) or --color-danger-solid; the label reads --color-fg-on-accent or --color-fg-on-popkin. All seven Popkin colours carry white text above 4.5:1 in both themes, so the Popkin variant needs no dark override. Set data-accent on an ancestor to change the colour.

Accessibility

Role and pattern

Native <button type="button">, or <a> with the same classes when it navigates (Start a Popkin, Go to Lakeside Weekend). Never a <div>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceActivates the button; a link styled as a button activates on Enter only.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only. On filled buttons the offset gap shows the page, so the ring reads against both.

Labelling

The visible label is the name. An icon inside a labelled button is aria-hidden. A busy button keeps a name that says what is happening.

Motion

Press scales to 97% over --duration-fast with --ease-pop; background fades over the same time. Durations come from tokens, which are near zero under prefers-reduced-motion, so the press scale and colour fades disappear without extra CSS.

Touch

Every size is at least 44px tall. Adjacent block buttons sit 12px apart.

Content

  • Labels are verbs in sentence case, three words at most: "Start a Popkin", "Pop it up", "Say hi to everyone".
  • Name the thing when it helps: "Go to Lakeside Weekend", "Delete my account".
  • The escape is warm, not "Cancel": "Not yet", "Stay", "Keep my account".
  • Busy labels say what is happening and end with an ellipsis: "Joining…".
