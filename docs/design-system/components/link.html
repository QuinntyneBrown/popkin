Link

Links go somewhere. Inline links are underlined coral-deep; text buttons are the unadorned links under a primary action.

WCAG 2.2 AAStatus: stableNative <a href>

Overview

Use a link to move to another screen or section. Use the text button style (.text-btn) for secondary routes under a primary button ("Already have an account? Sign in", "Use a different number"). Use a button to take an action.

Anatomy

  1. Lead-in (optional)Muted Inter 600, sets context.
  2. Link textCoral-deep, the part that names the destination.
  3. Hit areaAt least 44px tall.

Responsive behaviour

  • Text buttons centre under the block button they belong to.
  • Inline links wrap with their sentence; never truncate a link.

Theming

Links read --color-fg-link (coral-deep in light, light coral in dark) and --color-fg-link-hover.

Accessibility

Role and pattern

Native <a href>. A text button that performs an action ("Send a new code") is a <button> with the same class.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the link.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only.

Labelling

Link text names the destination on its own ("Sign in", "See all photos"). A "See all" link carries visually hidden context.

Contrast

Link on the page

Motion

None.

Touch

Text buttons and section links are 44px tall; inline links rely on line height and are never the only route to an action.

Content

  • "See all", not "View more" or "Click here".
  • The lead-in is a question; the link is the answer: "Already have an account? Sign in".
