Data table

A list of records that reads as a table from 768 px and as stacked records on phones, with a toolbar of search and filters above it.

WCAG 2.2 AAStatus: stableAdmin app<table>

Overview

Use for any admin list of like records: people, Popkins, jobs, exports, requests, the audit log. Not for a handful of facts about one record (use Key values).

Anatomy

  1. Toolbartoolbar: a search field and a segmented filter, above the panel.
  2. Header rowA real <thead>; on phones it is visually hidden and each cell shows its column from data-label.
  3. Primary cellwho: avatar or tile, a linked name, a sub-line.
  4. CellsNumbers right-aligned and tabular (data-table__num); actions right-aligned (data-table__end).
  5. Group rowtable-group: a day heading in the audit log.

A row with a link highlights on hover; the link underlines on hover and takes the focus ring. A selected row is aria-selected="true" on --color-accent-subtle.

Responsive behaviour

  • Under 768 px each row becomes a record: the primary cell on top, then one line per column with its name on the left and its value on the right; empty cells and the Actions label are hidden.
  • From 768 px a full table; a table wider than its panel scrolls inside table-wrap, never the page.
  • The toolbar wraps: search takes the full width on phones, the filter scrolls sideways rather than wrapping its labels.

Theming

Text tokens on --color-bg-surface, hairlines in --color-border-default, hover --color-bg-subtle.

Accessibility

Role and pattern

A native <table> with aria-label, <th scope="col"> headings. The stacked view keeps the table in the accessibility tree; the visually hidden header still names the columns.

Keyboard

KeyAction
Tab / Shift+TabMoves focus through the links and buttons in DOM order.
EnterFollows a link; activates a button (so does Space).

Focus

The shared ring: --focus-ring-width of --color-focus-ring at --focus-ring-offset, on :focus-visible only.

Labelling

The table's aria-label says what it lists; each row's link is the record's name.

Contrast

Cell text
Column heading
Error under a cell

Motion

None.

Touch

Row actions are small buttons, 36px tall, with space between them.

Content

  • Column headings are short nouns in sentence case.
  • Dates are relative while recent (4 min ago, Yesterday), absolute after (6 Jul).
  • Counts use thousands separators.
