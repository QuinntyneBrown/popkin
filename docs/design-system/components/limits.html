Limit row and save bar

A platform limit as a number with its unit and what it guards, and the bar that gathers unsaved changes until they are saved with a reason.

WCAG 2.2 AAStatus: stableAdmin app<input type="number"> + <div role="region">

Overview

Use only on Limits. Edits collect in the save bar at the foot of the page; Save opens a dialog listing each change from old to new and asking why, for the audit log.

Anatomy

  1. Namelimit__name, the field's label.
  2. HelpWhat the limit guards.
  3. ValueA number field with its unit beside it.
  4. Save barsave-bar: how many changes, Discard and Save.

    Sizes

    One size.

    States

    2 unsaved changesDiscardSave limits
    2 unsaved changesDiscardSave limits

    The value follows the text field's states (focus, invalid with its message, disabled for a Viewer).

    Responsive behaviour

    • Limits are one column under 1024 px and two from 1024 px.
    • The save bar sticks to the foot of the viewport while there are changes; its buttons go full width under 640 px.

    Theming

    Field tokens; the save bar is --color-bg-inverse so it stands out from the panels.

    Accessibility

    Role and pattern

    Each value is a labelled number input; the save bar is a region labelled "Unsaved changes" and its count is announced politely.

    Keyboard

    KeyAction
    Tab / Shift+TabMoves focus through the links and buttons in DOM order.
    ↑ ↓Step the number.
    EnterFollows a link; activates a button (so does Space).

    Focus

    The shared ring: --focus-ring-width of --color-focus-ring at --focus-ring-offset, on :focus-visible only.

    Labelling

    The limit's name labels its field; the help is its description (aria-describedby).

    Contrast

    Save bar text
    Help
    Error

    Motion

    The bar rises in over --duration-base; it appears at once under reduced motion.

    Touch

    Fields are 48px tall.

    Content

    • Name the limit for what a person does: Photo upload size, Sign-in codes an hour.
    • Units are words: MB, codes, per hour.
