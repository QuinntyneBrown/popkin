Textarea

A multi-line field for a comment on an experience. It grows with its text and stops at the limit.

WCAG 2.2 AAStatus: stableNative <textarea>

Overview

Use it where people write more than a line: a comment on an experience. Chat messages use the composer instead.

Anatomy

  1. LabelAs a text field.
  2. FieldAt least 96px, 16px radius, 2px edge, resizes vertically.
  3. Help, count or errorUnder the field.

Variants

Up to 500 characters.
With help.
HTML
<div class="field"><label class="field__label" for="c-x">Your comment</label><textarea class="textarea" id="c-x" rows="3" maxlength="500" >Would do it every morning if I could.</textarea><span class="field__hint">Up to 500 characters.</span></div>

Sizes

One size; it grows with its content.
