Component · Identity

Logo

The mark is a speech bubble with a smaller one popping off it: the group talks, someone new pops in. The wordmark is lowercase Rubik with the i's dot as the pop.

Overview

Use the full logo in the landing header and footer and on My Popkins; the coral wordmark alone on the welcome and invite screens; the app icon at small sizes.

Anatomy

  1. MarkTwo circles with a bite between them, so the pop stays separate down to 16px.
  2. WordmarkRubik 560, tracked −0.03em; the dotless ı with a coral dot.

Static display: there is nothing to press, so there are no interaction states. Both themes are shown below.

Responsive behaviour

  • The landing header uses the 28px logo at every width.
  • The welcome screen uses the 30px coral wordmark.

Theming

The mark reads --color-accent; the wordmark reads the text colour, so it flips to cream in dark. The app icon is coral with a white mark in both themes.

Accessibility

Role and pattern

An <svg aria-hidden> mark beside a wordmark with role="img" aria-label="popkin"; inside a link the link takes the name.

Keyboard

KeyAction
—Not focusable; it is read in place.
TabFocuses the logo when it is a home link.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only.

Labelling

The wordmark is named "popkin"; the mark is decorative.

Motion

None.

Touch

As a home link it is at least 44px tall.

Content

  • Always lowercase: popkin. In sentences the product is "Popkin".
