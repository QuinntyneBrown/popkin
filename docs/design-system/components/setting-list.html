Setting list

Things a member sets one by one: each Popkin's level, each birthday's lead time, who is muted.

Overview

A ruled list of things a member sets one by one: how much each Popkin tells them (Everything, Just for me, Muted), how early each birthday reminder comes, and who is muted. Each row is a face or tile, a name, a line that says what is set now, and the control at the end.

For one setting on a card use the switch's setting row; for the admin's read-only configuration use the settings list.

Anatomy

  1. LeadA Popkin tile or an avatar, 40px.
  2. Name and state lineThe line changes with the setting ("Muted. Nothing but reminders").
  3. ControlA level picker, a select and switch, or a button.

Responsive behaviour

  • Below 640px a Popkin row stacks: name above, level picker below, aligned left. From 640px the picker sits at the end of the row.
  • A reminder row wraps its select and switch under the name when the name needs 14rem.

Theming

Chosen level: the surface with --shadow-1; Muted chosen: --color-bg-inverse. The switch reads --accent-line; a muted Popkin's tile goes grey (popkin-tile--muted).

Accessibility

Role and pattern

The level picker is a WAI-ARIA Radio Group (role="radiogroup", each option role="radio" with aria-checked), labelled "How much you hear from Lakeside Weekend". The select is native; the switch is role="switch".

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
← / →In the level picker, moves to and chooses the previous or next level.
SpaceToggles a switch; opens a select.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only.

Labelling

Every control names its row: "When to remind you about Grace Adeyemi", "Unmute Sam Ortega" (the name is visually hidden after "Unmute").

Contrast

State line
Muted level
Unchosen level on its track

Motion

The chosen level's surface fades in; no slide.

Touch

Levels are 36px tall in a 44px pill; the row is at least 64px.

Content

  • The state line says the consequence: "Muted. Nothing but reminders", not "Muted".
  • Lead times read as the person says them: "1 week before", "On the day".
  • An empty list says what that means for the member.
