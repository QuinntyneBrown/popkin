Announcement preview

A sketch of the Popkin app with the announcement's banner on top, so an admin sees what everyone will see before publishing.

Overview

Use only on Announcements, beside the form. A loud announcement (an outage) uses banner--loud.

Anatomy

  2. App sketchapp-preview__rows: tiles and lines standing for My Popkins.
