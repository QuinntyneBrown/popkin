Admin sign-in card

The signed-out frame of the admin app: a centred card on the sand page with the brand, a title, a short form or message and a way out.

Overview

Use for sign in, the code step, Not an admin, not found and server error in the admin app. Not for the Popkin app's sign in, which uses Screen and layout.

Anatomy

  1. BrandMark, wordmark, Admin tag and the environment.
  2. Title and leadWhat this step is.
  3. FormOne field and one button.
  4. FootA way out: the Popkin app, or a link back.

Responsive behaviour

  • Under 640 px the card fills the width with the page's gutter; from 640 px it is centred.

Theming

The card is --color-bg-surface on --color-bg-subtle.

Accessibility

Role and pattern

A <form> with one labelled field; errors are linked with aria-describedby and announced.

Keyboard

KeyAction
Tab / Shift+TabMoves focus through the links and buttons in DOM order.
EnterSubmits the form.

Focus

The shared ring: --focus-ring-width of --color-focus-ring at --focus-ring-offset, on :focus-visible only. The field takes focus when the step opens.

Labelling

The field's label says what to enter: Staff email, 6-digit code.

Motion

None.

Touch

The field and button are 56px tall.
