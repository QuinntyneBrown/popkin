Tooltip

Icon buttons repeat their name in a native tooltip for pointer users. Popkin does not use custom tooltips.

WCAG 2.2 AAStatus: stableNative title

Overview

Every icon-only button sets title to the same words as its aria-label. Anything longer than a name belongs in visible text.

Anatomy

  1. Namearia-label for assistive technology.
  2. Tooltiptitle, shown by the browser on hover.

Variants

Hover to see the browser tooltip.

Sizes

Browser drawn.

States

The browser draws the tooltip; it follows the operating system theme.

Responsive behaviour

  • Touch screens show no tooltip; the icon must be familiar or the action must be named in text.

Theming

Drawn by the browser.

Accessibility

Role and pattern

Native title alongside aria-label; no role="tooltip".

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
—Keyboard users get the name from assistive technology; the native tooltip is pointer only.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only.

Labelling

The label and title match.

Contrast

Icon

Motion

None.

Touch

Not shown on touch.

Content

  • The tooltip repeats the name; it never adds instructions.
