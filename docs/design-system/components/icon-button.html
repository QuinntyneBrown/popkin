Icon button

A 44px round button that holds one icon: back, close, settings, call, scan. It always carries a name and a tooltip.

WCAG 2.2 AAStatus: stableNative <button> + aria-label

Overview

Use an icon button in bars and headers where the icon is universally understood. When the action needs a word, use a button. The send button in the composer is the one filled icon button that carries the brand colour.

Anatomy

  1. Icon24px Lucide icon (28px for back chevrons), 2px stroke, currentColor.
  2. Hit area44 × 44px circle; sand fill on hover.

Variants

Plain, filled (sand), on a card (over a photo), Popkin coloured, send.

States

Plain
Send

The send button is disabled until the message field has text.

Responsive behaviour

  • Same size at every width; icon buttons never grow.
  • In a top bar the back button is first and the actions last, so the title keeps the middle.

Theming

Plain icon buttons inherit the text colour. .icon-btn--popkin reads --accent-text, which is darkened in light and lightened in dark so it passes on the canvas.

Accessibility

Role and pattern

Native <button>, or <a> when it navigates (Back).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceActivates.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only.

Labelling

aria-label with the verb or destination ("Back", "My Popkins", "Start group call", "Call Walt") and the same text in title for a pointer tooltip. The SVG is aria-hidden.

Contrast

Icon on the page
Send icon on coral
Icon on the stage

Motion

Hover fill fades and press scales over --duration-fast. Durations come from tokens, which are near zero under prefers-reduced-motion, so the press scale and colour fades disappear without extra CSS.

Touch

44 × 44px; in the composer the 40px buttons sit inside the 48px field, which is itself a target.

Content

  • Names are short verbs or places: "Close", "Back", "Save photo", "Scan to join".
  • Never rely on a tooltip alone; the name must be in aria-label.
