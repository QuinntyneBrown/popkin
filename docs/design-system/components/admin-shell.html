Admin shell

The frame every signed-in admin screen sits in: a sidebar of grouped sections from 1024 px, a top bar with a menu drawer below it, the environment always on screen.

Overview

Use for every admin screen after sign-in. It carries the brand with its Admin tag, the Production tag (so no one mistakes it for staging), six groups of sections with counts waiting beside Reports, Jobs and Album exports, and the signed-in admin with Sign out. A Viewer gets a notice under the bar. Not for the Popkin app, whose chrome is the top bar and Popkin tabs.

Anatomy

  1. BrandThe mark, the wordmark and topbar__app reading Admin; links to the dashboard.
  2. Environment tagenv-tag: a danger dot and the word Production.
  3. Group labeladmin-nav__label, an <h2> naming the list under it.
  4. Section linkadmin-nav__item: icon, label, an optional count badge; aria-current="page" on the open section (a detail page lights up its list).
  5. Signed-in adminadmin-nav__me: avatar, name, role and a Sign out icon button.

The current section is ink with paper text and a heavier label, so it is told apart by more than colour; a count badge turns coral on it. Both themes are shown above.

Responsive behaviour

  • Under 1024 px the sidebar is hidden and a sticky 56px top bar takes its place: menu, brand, Production tag. The menu opens the same list as a drawer from the left (dialogs/menu).
  • From 1024 px the sidebar is fixed at 16rem, full height, and scrolls on its own; the page beside it scrolls separately.
  • The page body is centred to 77.5rem with 16px side padding under 768 px and 32px from 768 px.

Theming

Reads surface, subtle and inverse tokens only: the sidebar and bar are --color-bg-surface, the page is --color-bg-subtle, the current item --color-bg-inverse. The brand's mark reads --color-accent; no Popkin colour applies in the admin app.

Accessibility

Role and pattern

Landmarks: <aside> holding <nav aria-label="Admin">; each group is a list labelled by its <h2>. The drawer is a modal dialog (WAI-ARIA Dialog pattern) with the page behind it inert.

Keyboard

KeyAction
Tab / Shift+TabMoves focus through the links and buttons in DOM order.
EnterFollows a link; activates a button (so does Space).
EscCloses the drawer and returns focus to the menu button.

Focus

The shared ring: --focus-ring-width of --color-focus-ring at --focus-ring-offset, on :focus-visible only. Opening the drawer moves focus to its close button; closing it returns focus to the menu button.

Labelling

Each link's text names the section; a count badge carries aria-label="5 waiting". The menu and Sign out icon buttons have accessible names and tooltips.

Contrast

Section label
Current section
Group label
Count badge

Motion

The drawer slides in over --duration-base; under prefers-reduced-motion it fades instead.

Touch

Section links are 36px tall in a dense list; the drawer's backdrop closes it on tap.

Content

  • Section names are nouns in sentence case: Deletion queue, Admins & roles.
  • Counts are things waiting for an admin, never totals.
