Hero

The first section of the landing page: the headline, one paragraph, the main action, and a preview of a Popkin.

WCAG 2.2 AAStatus: stableLanding page only

Overview

Use it once, at the top of the public landing page. It says what Popkin is in one headline and one paragraph, offers the one main action, and shows a Popkin as its members see it. The preview is a picture: nothing in it can be pressed. Inside the app a screen starts with the top bar or the home header instead.

Anatomy

  1. HeadlineThe page’s h1, in the hero type style.
  2. LeadOne paragraph, no wider than the measure.
  3. ActionsThe primary button and a muted note beside it.
  4. Preview cardA Popkin’s tile, name, members, time left, three photos and two messages.
  5. QR codeA small code on its own card, tilted, over the corner of the preview. From 576px.

Responsive behaviour

  • Under 576px: one column, the preview under the text, no QR code. The headline is 40px.
  • From 576px: the headline is 52px, the card has more padding and the QR code shows over its corner.
  • From 768px: more room above the hero.
  • From 992px: two columns, the text beside the preview, and the headline is 64px (L2-001 AC6).
  • The preview is never wider than --layout-hero-art-max, and the page never scrolls sideways (L2-001 AC5).

Theming

The card is --color-bg-surface on the canvas. The preview carries a Popkin colour through data-accent on .hero__art: the tile, the time left and the member’s own message read it. The QR code stays dark on white in both themes (L2-059 AC4).

Accessibility

Role and pattern

A <section> that holds the page’s only <h1>. The action is a link. In the preview the tile, the faces and the photos are decoration (aria-hidden, empty alt); the name, the count, the time left and the two messages are text; the QR code is role="img" named "QR code for popk.in/lakeside" (L2-057 AC6).

Keyboard

KeyAction
TabMoves to "Start a Popkin". Nothing in the preview takes focus.
EnterOpens the sign-up screen.

Focus

The shared ring on the button.

Labelling

The button’s text is its name. The QR code is named after the link it holds. Below 576px the code is display: none, so it leaves the accessibility tree too.

Content

  • Headline: "Your people, popped up in seconds." One sentence, with its full stop.
  • One paragraph that says what Popkin is and that it is free.
  • The action is always "Start a Popkin"; the note beside it is "Free. Takes about a minute."
  • The preview shows an invented Popkin with real-looking content, never a real group.
