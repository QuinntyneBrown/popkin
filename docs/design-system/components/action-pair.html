Action pair

Two actions of equal standing: stacked on a phone, side by side wherever their column is wide enough for two.

Overview

Use it when a screen ends in two ways forward, as the welcome screen does with "Start a Popkin" and "Join with a code". Both are block buttons; the first is the primary one. For one main action with a quieter link under it, use a button and a text button.

Anatomy

  1. First actionThe primary button.
  2. Second actionThe secondary button, as wide as the first.

Sizes

One size.

States

Start a PopkinJoin with a code
Start a PopkinJoin with a code

The pair has no states of its own; each button has its own.

Responsive behaviour

  • Under 640px: stacked, 12px apart.
  • From 640px: side by side, equally wide.
  • From 768px: stacked again, because the split screen halves the column.
  • From 1280px: side by side again.

Theming

None of its own.

Accessibility

Role and pattern

A plain <div>: the two actions are links or buttons in reading order, the primary one first at every width.
