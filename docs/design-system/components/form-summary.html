Form summary

When a form is sent with mistakes, a coral box at the top lists each one as a link to its field, and focus moves to it.

WCAG 2.2 AAStatus: stablerole="alert"

Overview

Use it on every form that can fail validation on submit, together with the inline errors under each field. Use an alert for a failure that is not about a field (the code could not be sent).

Anatomy

  1. Title"One thing to fix" or "2 things to fix".
  2. ListOne link per error, naming the field and the fix.

Variants

One thing to fix

  • Your name: enter a name so people know who you are.
One error.
HTML
<div class="form-summary" role="alert" tabindex="-1"><h2>One thing to fix</h2><ul><li><a href="#anatomy">Your name: enter a name so people know who you are.</a></li></ul></div>

2 things to fix

  • Your name: enter a name so people know who you are.
  • Phone number: that number looks a digit short.
Several errors.

<div class="form-summary" role="alert" tabindex="-1"><h2>2 things to fix</h2><ul><li><a href="#anatomy">Your name: enter a name so people know who you are.</a></li><li><a href="#variants">Phone number: that number looks a digit short.</a></li></ul></div>

Role and pattern

Keyboard

KeyAction

Enter on a linkMoves focus to the field.

Labelling
