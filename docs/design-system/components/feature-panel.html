Feature panel

One feature with how far it reaches: Off, Chosen Popkins or Everyone, who changed it and when, and the chosen Popkins as removable chips.

Overview

Use only on Features, one panel per feature (Plan, Schedules). Choosing a mode opens a dialog that says what changes; adding a Popkin opens a picker.

Anatomy

  1. Name and aboutWhat the feature is.
  2. ReachWhere it is on now, and since when by whom (L2-076).
  3. ModeA segmented radio group: Off, Chosen Popkins, Everyone.
  4. Chosenchosen: a chip per Popkin with a remove button, and Add a Popkin.

The mode follows the segmented control's states; a chip's remove button takes the focus ring.

Responsive behaviour

  • Under 768 px the mode control drops under the feature's name; chips wrap.

Theming

Surface, subtle and inverse tokens; the chosen mode is --color-bg-inverse.

Accessibility

Role and pattern

The mode is a radio group (WAI-ARIA Radio Group pattern); the picker's results are a list of checkable options.

Keyboard

KeyAction
Tab / Shift+TabMoves focus through the links and buttons in DOM order.
← →Moves between modes.
EnterFollows a link; activates a button (so does Space).

Focus

The shared ring: --focus-ring-width of --color-focus-ring at --focus-ring-offset, on :focus-visible only.

Labelling

Each chip's remove button is named "Remove Lakeside Weekend".

Contrast

Chosen mode
Since line

Motion

None.

Touch

Chips are 40px tall; the remove button is a full target inside.

Content

  • Reach is a sentence: On in 3 chosen Popkins only.
  • Since names the admin: by Lena Fischer.
