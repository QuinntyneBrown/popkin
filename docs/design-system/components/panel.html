Panel

A surface on the sand page, with an optional title, subtitle, action and foot. Admin pages are panels in a grid.

Overview

Use for every group of admin content that needs an edge: a table, a chart, a form, a record's facts. Panels sit in panel-grid layouts. Not for the Popkin app, whose cards are Card.

Anatomy

  1. Headpanel__head: title (<h2>), subtitle, an optional action on the right.
  2. Bodypanel__body, padded; a table or list goes edge to edge without it.
  3. Footpanel__foot: a count, a link, a note.

A panel is static; what is inside it carries the states. Both themes are shown above.

Responsive behaviour

  • panel-grid is one column under 1024 px.
  • From 1024 px: --halves two equal columns, --main-aside a main column and a 22.5rem aside, --thirds three; --list-detail and --detail-aside pair a list with the record it opens.
  • panel-stack stacks panels in one grid cell with the same gap.

Theming

--color-bg-surface with a --color-border-default hairline; panel--danger edges it in --color-danger-border. In dark the surface is lighter than the page, so a panel reads as raised without a shadow.
