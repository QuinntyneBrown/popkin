Component · Identity

Chip

Pills that filter a list (Everyone / Mine, All / We did / Want to do), suggest a reply, or label a picture ("Restaurant") and an inviter.

WCAG 2.2 AAStatus: stableToggle buttons with aria-pressed

Overview

Filter chips toggle with aria-pressed; the pressed one is ink. Suggestion chips (outline) put text in the composer. Tags label media. Pills hold an avatar and a sentence ("Mara invited you").

Anatomy

  1. Pill40px, Inter 600 15px; ink when pressed, sand otherwise.

Variants

Filter chips.
HTML
<div class="chips" role="group" aria-label="Filter"><button class="chip" type="button" aria-pressed="true" >Everyone</button><button class="chip" type="button" aria-pressed="false">Mine</button></div>
Suggestion chips.
HTML
<button class="chip chip--outline" type="button">👋 Hey everyone!</button><button class="chip chip--outline" type="button">Who’s coming?</button>

Kind
Choice chips: one of a few, as a radio group. The chosen chip carries aria-checked; the arrow keys move and choose.
HTML
<div><span class="field__label" id="kind-l">Kind</span><div class="chips" role="radiogroup" aria-labelledby="kind-l"><button class="chip" type="button" role="radio" aria-checked="true">Something we did</button><button class="chip" type="button" role="radio" aria-checked="false" tabindex="-1">Restaurant</button><button class="chip" type="button" role="radio" aria-checked="false" tabindex="-1">Want to do</button></div></div>

Responsive behaviour

  • Filter rows scroll sideways rather than wrap when they do not fit.

Theming

Pressed: --color-bg-inverse and --color-fg-inverse; unpressed: --color-bg-subtle and --color-fg-muted.

Accessibility

Role and pattern

Filter chips are buttons with aria-pressed in a role="group" with a label; they filter in place.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Space, EnterPresses.

Focus

The shared ring: 3px --color-focus-ring (ink in light, cream in dark) at a 2px offset, on :focus-visible only.

Labelling

The group is named ("Filter"); each chip is a word.

Contrast

Pressed chip
Chip

Motion

Fill fades over --duration-fast.

Touch

40px tall chips with 8px gaps; suggestion chips 44px.

Content

  • One or two words; "Everyone", not "All photos from everyone".
