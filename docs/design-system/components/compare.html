Comparison table

Popkin beside a group chat, row by row: a real table whose two columns are told apart by a heading and an icon, never by colour alone.

Overview

Use it for the one comparison on the landing page. It is data in rows and columns, so it is a <table>: a screen reader reads "Photos, Group chat: Lost in the scroll; Popkin: A shared album the group keeps".

Anatomy

  1. CaptionSays what is compared. For assistive technology only.
  2. Column headings"Group chat", and the mark with "Popkin" in the accent colour. The first is hidden: "What".
  3. Row headingWhat is compared: "Joining".
  4. Their cellA grey dash and muted text.
  5. Our cellA green tick and full-strength text.

Responsive behaviour

  • Three equal columns at every width (table-layout: fixed); long words break rather than widen the table, so the page never scrolls sideways.
  • Under 576px: 14px text and 12px of padding. From 576px: 16px text and 16px by 24px of padding.
  • It sits in the narrow container, so a row is never too long to follow.

Theming

The table is a card: --color-bg-surface, the first shadow, hairlines between the rows of the body. The tick is --color-success-icon and the dash --color-fg-subtle in both themes.

Accessibility

Role and pattern

<table> with a <caption>, <th scope="col"> and <th scope="row">. The icons are aria-hidden: the column heading already says whose cell it is.

Keyboard

Nothing in it takes focus by itself; the links and buttons it holds are reached with Tab in reading order.

Focus

Nothing takes focus.

Labelling

The caption names the table: "A group chat compared with a Popkin". The first column’s heading, "What", is visually hidden but present, so no header cell is empty.

Content

  • Five rows: Joining, Photos, Plans, Video, The end (L2-001 AC4).
  • A cell is a few words, with no full stop. Say what happens, not that the other side is bad.
  • The columns differ in three ways at once: the heading, the icon (dash or tick) and the strength of the text (L2-057 AC5).
