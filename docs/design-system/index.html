How to use it

  1. Link tokens/tokens.css, then assets/components.css. The fonts load from assets/fonts/.
  2. Use the class names on each component page; put data-accent on the screen to give it the Popkin's colour, and data-theme to force a theme.
  3. Read colours, sizes and durations only through tokens. tokens/tokens.json is the same set in DTCG format.
  4. In the Angular app the tokens and component styles move into the components library, one pk-* component per page here (ADR 0007).
