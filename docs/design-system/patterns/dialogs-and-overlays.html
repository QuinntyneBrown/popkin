Pattern

Dialogs and overlays

Short tasks open in a sheet over the screen they belong to. Under 640px it rises from the bottom; wider, it is a centred card.

Overview

Popkin uses one overlay: the dialog (Angular CDK Dialog). The settings menu is a dialog with menu rows, so it works the same with touch and keys.

When to use what

TaskUse
Invite, edit, comment, add photos, share an experienceDialog with a form
Choose one of a few actions (Popkin settings)Dialog with menu rows
Confirm something that cannot be undoneDialog with danger and a safe default
A flow with several stepsScreens, not a dialog

Structure

Sign out of Popkin?

You’ll need a new code to sign back in on this device.

A confirmation sheet.

States

  • Default, busy, invalid, failed; the page behind is inert.

Responsive behaviour

  • Sheet under 640px; card from 640px.
  • The body scrolls; the header stays.

Accessibility

  • APG modal dialog: labelled, focus trapped, Escape closes, focus returns.
  • Focus starts on the first field or the safe action.

Content

  • Confirmations ask a question with the thing's name.
  • Buttons say what happens.
