Pattern

Popkin colour

Each Popkin picks one of seven colours. Its screens, main buttons, bubbles, badges and tabs take that colour, for everyone in it.

Overview

Coral is Popkin's own colour: the app outside a Popkin, primary actions, errors. Once you are inside a Popkin, its colour leads. Set data-accent once on the screen.

When to use what

ElementColour
Start a Popkin, Continue, Wrap it upCoral (primary)
Join, Pop it up, Group call, Say hiPopkin colour
Your own bubblesPopkin colour
Current tab, time left, tinted cardsPopkin colour mixed for text or tint
Unread counts outside a Popkin cardCoral
Errors and destructive actionsCoral, never the Popkin colour

States

  • Active: full colour. Wrapped up: the tile is muted and greyed.

Responsive behaviour

  • No change with width.

Accessibility

  • White on every Popkin colour is at least 4.55:1.
  • Tints, colour-as-text and edges are mixed per theme and pass (see the README table).
  • The colour is never the only cue.

Content

  • Colours have names, not codes: Coral, Teal, Sky, Berry, Leaf, Plum, Amber.
