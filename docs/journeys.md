# Journeys

Ordered by value to the product, most valuable first. The number is the journey's fixed ID, which
code, tests and docs cite, so it never changes when the order does. Effort is days for an
intermediate developer. Status is read from `docs/estimates/`: *Built* is every design of the
journey at 100%, *Built, polish left* is working end to end with the last 10 to 20% of its
designs open, and anything else names what is missing.

| # | Journey | Description | Effort (days) | Status |
|---|---------|-------------|---------------|--------|
| 1 | Start a Popkin | Visitor signs up with a code, starts a Popkin and gets its QR invite. | 10 | Built, polish left |

| 3 | Chat with everyone | Members send and receive live messages in the shared thread. | 5 | Built, polish left |
