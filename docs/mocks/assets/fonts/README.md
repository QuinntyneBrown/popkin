# Fonts

Nunito, Inter and Rubik, each as one variable `woff2` file covering the Latin range. All three are
licensed under the SIL Open Font License 1.1, which allows bundling and redistribution:

- Nunito: Copyright 2014 The Nunito Project Authors (https://github.com/googlefonts/nunito)
- Inter: Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter)
- Rubik: Copyright 2015 The Rubik Project Authors (https://github.com/googlefonts/rubik)

`../tokens.css` declares them with `@font-face`, so the mocks open from disk without a network.
