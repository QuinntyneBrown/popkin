# Support

## How to get help

This project uses [GitHub Issues](https://github.com/QuinntyneBrown/popkin/issues) to track bugs,
feature requests and questions. Search the existing issues before you open a new one, to avoid
duplicates.

| You want to | Do this |
|---|---|
| Report a bug | Open an issue with the **Bug report** template |
| Request a feature | Open an issue with the **Feature request** template |
| Ask a question | Open an issue with the **Question** label |
| Report a security vulnerability | Follow [`SECURITY.md`](SECURITY.md); never a public issue |

Before you ask, read the [README](README.md), [`AGENTS.md`](AGENTS.md) and the
[documentation in `docs/`](README.md#documentation); most questions about how the repository works
are answered there.

## Support policy

Popkin is maintained on a best-effort basis. There is no service-level agreement, and response
times vary.
